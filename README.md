# CYBERMG Map — stage 1

Статическая карта филиалов CYBERMG во Владивостоке на базе 2GIS MapGL.
Проект сохраняет исходную архитектуру `vlmap`: HTML + CSS + JavaScript, без сборщика и backend.

## Что изменено на этом этапе

- слой секторов удалён из интерфейса;
- добавлен `branches.js` с 6 филиалами CYBERMG;
- все 6 филиалов отрисовываются постоянными HTML-маркерами поверх карты;
- маркеры не зависят от zoom и не скрываются при приближении/отдалении;
- маркер содержит бренд CYBERMG и название филиала;
- подписи разведены экранными offsets, чтобы на общем плане города меньше перекрывались;
- клик по маркеру открывает карточку филиала и переход в 2ГИС;
- GPS теперь показывает ближайший филиал и расстояние до него;
- кнопка `Все филиалы` возвращает карту к общему виду;
- поиск, GPS, Smart POI и переход в 2ГИС сохранены;
- service worker переведён на новый cache namespace `cybermg-map-v11-branches`.

## Филиалы

Данные лежат в `branches.js` в формате:

```js
{
  id: 'russkaya',
  name: 'Русская',
  address: 'ул. Русская, 17/1',
  coordinates: [131.909251, 43.168245], // [longitude, latitude]
  labelOffset: [-118, -42]
}
```

Сейчас добавлены:

- Калинина — ул. Калинина, 283а ст2
- Светланская — ул. Светланская, 21
- Ульяновская — ул. Ульяновская, 8
- Русская — ул. Русская, 17/1
- Трамвайная — ул. Трамвайная, 14
- Сахалинская — ул. Сахалинская, 50В

## Где менять внешний вид маркеров

В `styles.css` блок:

```css
/* CYBERMG BRANCHES — stage 1 */
```

Основные классы:

- `.cybermg-branch-marker`
- `.cybermg-marker-dot`
- `.cybermg-marker-copy`

Бренд-жёлтый: `#FFC600`.

## Где меняется логика

В `app.js`:

- `renderBranches()` — создаёт 6 маркеров;
- `nearestBranch()` — определяет ближайший филиал;
- обработчик `[data-branch-id]` — открывает карточку филиала.

## Запуск локально

Не открывайте `index.html` через `file://`.

```bash
python -m http.server 8080
```

Затем:

```text
http://localhost:8080
```

## Деплой

Проект — обычная статика и не содержит привязки к конкретному домену или Timeweb Cloud.
Его можно публиковать тем же способом, которым сейчас публикуется исходный `vlmap`.

В переданном архиве нет GitHub Actions / Timeweb deployment config и нет строки
`nerlock1123-vlmap-254b.twc1.net`. Это означает, что домен и источник автодеплоя настроены вне файлов сайта.

После обновления production убедитесь, что API-ключ 2ГИС ограничен вашим production Origin.
