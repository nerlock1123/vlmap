# Владивосток — сектора v6

Рабочая мобильная версия поверх 2GIS MapGL.

## Готово

- финальная геометрия 6 секторов;
- поиск по адресу / названию места через 2GIS Places API;
- результаты поиска с координатами;
- автоматическое определение сектора для найденного объекта;
- клик по зданию / объекту карты: попытка получить название и адрес из Places API;
- клик в любую точку: сектор определяется даже без объекта;
- кнопка `Я здесь`: GPS телефона → точка → сектор;
- маркер выбранной точки;
- показать/скрыть сектора;
- кнопка возврата ко всему городу;
- мобильная нижняя карточка;
- PWA manifest: после публикации по HTTPS страницу можно добавить на главный экран.
- кнопка `2ГИС` в карточке выбранного объекта/адреса/точки.
  - организация → открывается карточка фирмы;
  - адрес/здание/место → карточка объекта;
  - произвольная точка/GPS → 2ГИС открывается на координатах.

## Как запускать локально

Не открывайте `index.html` двойным кликом через `file://`.
Запустите статический сервер:

    python -m http.server 8080

И откройте:

    http://localhost:8080

Поиск должен работать при доступе ключа к Places API.

## Геолокация

На `localhost` геолокация обычно разрешена браузером.
На телефоне для кнопки `Я здесь` нужен HTTPS.

## Публикация

Подойдёт любой статический HTTPS-хостинг:
- Cloudflare Pages
- GitHub Pages
- Netlify
- собственный домен / сервер

После публикации обязательно ограничьте ключ 2ГИС:
Platform Manager → API Keys → Restrictions → Origin
и разрешите только ваш HTTPS-домен.

## Важно

Ключ 2ГИС, который был предоставлен для задачи, уже вставлен в `config.js`.


## Кнопка 2ГИС

Используются официальные HTTPS deeplink-ссылки 2ГИС. На телефоне с установленным
2ГИС ссылка может открыться в приложении; без приложения откроется веб-версия.

Поиск в v6 больше не ограничен `one_branch`, поэтому может возвращать не только
организации, но и адресные/географические объекты.


## v7 — Performance + Gestures

Изменения относительно v6:

- включено вращение карты двумя пальцами;
- включён наклон / pitch двумя пальцами;
- zoom/pan остаются нативными MapGL;
- `graphicsPreset: 'auto'` — MapGL сам подбирает уровень графики под устройство;
- на мобильных отключён дорогостоящий `backdrop-filter`;
- облегчены тени поверх WebGL-карты;
- новая версия service worker (`vl-sectors-v7`);
- service worker теперь `skipWaiting()` + `clients.claim()`;
- во время тестирования используется network-first, чтобы новый деплой не маскировался старым кэшем.

Функциональность секторов, поиска, GPS и кнопки 2ГИС не менялась.


## v8 — Smart POI

Добавлен отдельный слой организаций, который работает через **Markers API**.

Логика:
- до zoom 13.3 дополнительных организаций нет;
- при приближении появляется небольшое число популярных организаций;
- чем ближе zoom, тем больше объектов;
- запрос выполняется только после события `idle`, когда карта полностью остановилась;
- область и zoom кэшируются в `sessionStorage` на 6 часов;
- повторное движение внутри уже загруженной ячейки не расходует API;
- максимум 60 запросов Markers API за одну сессию браузера;
- используется обычный WebGL `mapgl.Marker`, не тяжёлые HTML-маркеры;
- клик по Smart POI показывает сектор и кнопку перехода в 2ГИС;
- фоновые POI не расходуют Places API.

### Лимиты

- MapGL JS API — библиотека без лимита;
- Map Tiles API — расходуется при загрузке векторных тайлов карты;
- Places API — поиск и подробности обычного объекта;
- Markers API — Smart POI слой v8.

На demo key Markers API и Places API имеют отдельные лимиты по 1000 успешных запросов.


## v9 — Map Tiles optimization

Цель: снизить бессмысленную загрузку новых Map Tiles без ухудшения основной работы карты.

Изменения:
- вращение карты сохранено;
- 3D/pitch отключён;
- `minZoom: 10.2`;
- `maxZoom: 18.0`;
- добавлен `maxBounds` вокруг Владивостока и всех рабочих секторов:
  - west/south: `[131.78, 43.02]`
  - east/north: `[132.03, 43.23]`;
- `graphicsPreset: 'auto'` сохранён;
- Smart POI v8, Places, GPS, кнопка 2ГИС и геометрия секторов не изменялись;
- service worker обновлён до `vl-sectors-v9`.

Почему это экономит Map Tiles:
- пользователь не может случайно уйти далеко за рабочую территорию;
- нельзя открыть лишние уровни zoom за пределами разумного диапазона;
- отключён pitch, который увеличивает видимую область карты вдаль.


## v9 Hotfix 1

Исправлен белый экран после v9.

Причина:
`maxBounds` был передан в форме массива из двух точек.
MapGL ожидает `LngLatBounds` как объект:

    {
      southWest: [lon, lat],
      northEast: [lon, lat]
    }

Дополнительно добавлен fail-safe:
если оптимизированная инициализация карты когда-либо падает,
приложение автоматически повторяет запуск с базовой безопасной конфигурацией
вместо белого экрана.

Service worker cache: `vl-sectors-v9-hotfix1`.


## Dual key setup

Добавлен отдельный файл:

    backup-key.js

Вставьте второй ключ сюда:

    window.DGIS_BACKUP_KEY = 'ВАШ_ВТОРОЙ_КЛЮЧ';

Как переключиться на резервный ключ:

Откройте `config.js` и измените:

    DGIS_KEY_MODE: 'primary'

на:

    DGIS_KEY_MODE: 'backup'

Чтобы вернуться к основному ключу, снова поставьте `primary`.

Ключ выбран один раз при загрузке страницы и используется одновременно для:
- MapGL / Map Tiles;
- Places API;
- Markers API.

Это намеренно сделано как явное переключение, а не скрытая автоматическая ротация:
так проще контролировать, какой ключ сейчас расходует лимиты и диагностировать ошибки.

## 3 ключа 2ГИС

Файлы:
- основной ключ — `config.js`
- резерв №1 — `backup-key.js`
- резерв №2 — `backup-key-2.js`

Вставьте ключ №2 сюда:

    window.DGIS_BACKUP_KEY_2 = 'ВАШ_КЛЮЧ';

В `config.js` меняется только:

    DGIS_KEY_MODE: 'primary'

    DGIS_KEY_MODE: 'backup2'  // резерв №2

После изменения сделайте commit/push и дождитесь нового деплоя.


## v10 — Live Location

Добавлена постоянная геопозиция через браузерный Geolocation API.

### Управление

`GPS`
- первое нажатие запускает `navigator.geolocation.watchPosition()`;
- появляется отдельная синяя живая точка;
- сектор, точность GPS и скорость обновляются автоматически;
- повторное нажатие полностью выключает GPS.

`Следовать`
- доступна после получения первой GPS-точки;
- карта следует за пользователем;
- камера НЕ центрируется при каждом GPS-событии;
- она сдвигается только когда живая точка подходит к краю центральной зоны;
- это уменьшает лишние подгрузки Map Tiles.

`Весь город`
- отключает режим следования камеры;
- сам GPS при этом продолжает работать.

### Расход API 2ГИС

Сам `watchPosition()`:
- Places API: 0
- Markers API: 0
- MapGL JS API: дополнительных запросов нет

Map Tiles могут загружаться только когда камера реально перемещается в новую область
или на новый уровень масштаба.

### Требования

На телефоне постоянная геолокация требует HTTPS и разрешения пользователя.
При сворачивании браузера iOS/Android могут ограничивать частоту обновлений —
это ограничение мобильной ОС/браузера, а не 2ГИС.
