# Владивосток — сектора v6

Рабочая мобильная версия поверх 2GIS MapGL.

## Готово

- финальная геометрия 6 секторов;
- поиск по адресу / названию места через 2GIS Places API;
- результаты поиска с координатами;
- автоматическое определение сектора для найденного объекта;
- клик по зданию / объекту карты: попытка получить название и адрес из Places API;
- клик в любую точку: сектор определяется даже без объекта;
- кнопка `Я здесь`: GPS телефона → точка → сектор;
- маркер выбранной точки;
- показать/скрыть сектора;
- кнопка возврата ко всему городу;
- мобильная нижняя карточка;
- PWA manifest: после публикации по HTTPS страницу можно добавить на главный экран.
- кнопка `2ГИС` в карточке выбранного объекта/адреса/точки.
  - организация → открывается карточка фирмы;
  - адрес/здание/место → карточка объекта;
  - произвольная точка/GPS → 2ГИС открывается на координатах.

## Как запускать локально

Не открывайте `index.html` двойным кликом через `file://`.
Запустите статический сервер:

    python -m http.server 8080

И откройте:

    http://localhost:8080

Поиск должен работать при доступе ключа к Places API.

## Геолокация

На `localhost` геолокация обычно разрешена браузером.
На телефоне для кнопки `Я здесь` нужен HTTPS.

## Публикация

Подойдёт любой статический HTTPS-хостинг:
- Cloudflare Pages
- GitHub Pages
- Netlify
- собственный домен / сервер

После публикации обязательно ограничьте ключ 2ГИС:
Platform Manager → API Keys → Restrictions → Origin
и разрешите только ваш HTTPS-домен.

## Важно

Ключ 2ГИС, который был предоставлен для задачи, уже вставлен в `config.js`.


## Кнопка 2ГИС

Используются официальные HTTPS deeplink-ссылки 2ГИС. На телефоне с установленным
2ГИС ссылка может открыться в приложении; без приложения откроется веб-версия.

Поиск в v6 больше не ограничен `one_branch`, поэтому может возвращать не только
организации, но и адресные/географические объекты.
