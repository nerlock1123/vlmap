# CYBERMG Map — Stage 3

Текущая версия карты Владивостока на базе 2GIS MapGL.

## Что есть в Stage 3

- 6 постоянно видимых филиалов CYBERMG.
- Слой **Статика**: 21 остановка из таблицы статики.
  - октябрь / декабрь;
  - зелёная точка — свободно;
  - красная точка — занято.
- Слой **Медиа**: 30 остановок из прайса медиафасадов.
  - отдельные синие метки M1–M30;
  - в карточке: размер, время работы, хронометраж, блок, выходы/день и цена.
- Слои **Статика** и **Медиа** независимо включаются/выключаются кнопками в верхней панели.
- Слой «Места» 2ГИС остаётся отдельным и выключен по умолчанию.
- Service Worker cache: `cybermg-map-v15-stage3-layers`.

## Файлы данных

- `branches.js` — филиалы CYBERMG.
- `stops.js` — статичные рекламные остановки.
- `media-stops.js` — остановки с медиаэкранами.
- `assets/stops/` — SVG метки статики.
- `assets/media-stops/` — SVG метки медиа.
